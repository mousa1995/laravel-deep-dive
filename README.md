# Laravel Learning Notebook

دفترچه ساختاریافته یادگیری Laravel.

هر مفهوم یک پوشه مستقل دارد و یادگیری آن از طریق چک لیست، مطالعه، مثال، تمرین و یادداشت انجام می شود.

## اصل کار

هر مفهوم:

- مطالعه مستندات رسمی
- خلاصه نویسی
- اجرای مثال
- تمرین اصلی
- تمرین اضافه
- توضیح با زبان خودم
- ثبت سوال های باز
- مرور
